Hakkımda

Zonguldak Bülent Ecevit Üniversitesi Bilgisayar Mühendisliği son sınıf öğrencisiyim. Üst sınıflardan ders alarak bitirme projesi dışındaki derslerimi tamamladım. Özellikle yapay zeka destekli uygulamalar, RAG mimarileri, büyük dil modelleri ve backend geliştirme alanlarına ilgi duyuyorum. TRTEK Yazılım'daki stajım sırasında ASP.NET Core MVC, Entity Framework Core ve SQL Server kullanarak katmanlı mimariye sahip bir Ağız ve Diş Sağlığı Takip Uygulaması geliştirdim. Sürekli öğrenebileceğim ve uzun vadeli katkı sunabileceğim projelerde yer almayı hedefliyorum.
